# Nonwoven Absorption ML Dashboard

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Community Cloud
1. Create a GitHub repository.
2. Upload `app.py` and `requirements.txt`.
3. Open Streamlit Community Cloud.
4. Deploy the repository with `app.py` as the main file.

The dashboard reproduces the notebook's six-model comparison logic, target switch, LOOCV R², A5/B5/C5 R², dataset view, correlation analysis, and interactive predictions.
